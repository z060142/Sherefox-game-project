# 狐耳摩斯 Ch.1～3 原型：音樂與音效需求清單

狀態：2026-11-06。給負責找素材的人用：照表找、照檔名交、照 `audio/CREDITS.md` 登記來源。曲名、ID、長度的設計依據是 `design/00-overview.md` 十一、`design/01-systems.md` 2.6、4.4、4.7，美術氣質依據 `design/03-art.md`。

## 0. 先看這裡

- 世界觀：1887 年倫敦、維多利亞蒸氣龐克、報紙與偵探。**暖色、帶一點機械感、不要太現代**（避免電子合成與流行編曲）。
- 優先順序：先找「必要」，原型就能完整玩完 Ch.1～3；「建議」之後再補。素材沒到位的音效，遊戲端先不播（不會報錯）。
- 全部是單一檔案、單次播放的素材；**不需要語音**（原型不做配音）、不需要環境音。
- 授權必須允許隨遊戲散布（見第 4 節）。

## 1. 範圍

只含 Ch.1～3 實際會出現的畫面：標題、報紙（開場頭版與轉場）、對話（日常與事件）、蒐證、線索板（含證物冊）、論戰（含 Ch.1 布丁論戰、Ch.3 熱身）、結算、片尾卡。

**不在本批**（Ch.1～3 不會出現，之後再說）：

- BGM10（絕境重組）、BGM13～BGM20。
- 逆論破、二連論破、反擊論破、絕境四個全幕大字的音效（Ch.4 起才有）。
- 每個 `SFX_CUT_*` 的 `_SHORT` 版（原型沒有「大字演出：縮短」設定）。
- 語音（VO_*）、環境音（蒸氣、雨霧、列車、群眾）。

### 格式與規格

- **格式（2026-11-06 更新，XTAtrium AT-050）**：框架的 miniaudio 內建 WAV、FLAC、MP3、OGG Vorbis 解碼器，背景音樂另有可循環的音樂頻道（整檔無縫循環，或指定 loopStart／loopEnd 的 PCM 樣本位置）、淡入淡出與交叉淡化、分類音量（master／se／bgm／voice／ambience）。
- 規格：**背景音樂用 OGG Vorbis**（44.1 kHz、立體聲、品質約 q6），需要無縫循環；若曲子有前奏，請附上循環起點與終點的樣本位置。**音效用 WAV**（44.1 kHz、16-bit，單聲道或立體聲皆可）。
- 檔案大小：OGG 背景音樂整套預估 20～40 MB。
- 若手上只有 MP3 的素材也可以直接交；不要為了格式重新轉檔成更大的檔案。
- 循環：頭尾切在小節線上，結尾不留殘響與靜音，頭尾接起來聽不出縫；**不要附獨立前奏檔**（原型只做整檔循環）。

## 3. 音效（SFX）

ID 命名：設計文件已有的用原名；其餘用 `SFX_<區域>_<名稱>`（區域：UI、INV 蒐證、BOARD 線索板、DEB 論戰、CUT 大字、STAMP 印章、RES 結算）。長度為目標值，交付可差 ±0.1 秒。「簡短」類音效盡量不超過 1 秒，**開頭立即有聲，不要留空白**。

## 4. 檔案交付方式

- 資料夾：專案根目錄下的 `audio/`，檔名＝ID；背景音樂副檔名 `.ogg`，音效 `.wav`。

```
audio/
  bgm/BGM02.ogg, BGM05.ogg ...
  sfx/SFX_UI_CONFIRM.wav, SFX_CUT_RONPA_TAIKO.wav ...
  CREDITS.md
```

- 響度：
  - **BGM**：整首約 −16 LUFS（integrated），真峰值 ≤ −1 dBTP；各曲之間音量感一致，避免換曲時忽大忽小。
  - **SFX**：峰值 ≤ −1 dBFS，不要削波。同類音效之間響度大致一致；大字與論破的重擊（TAIKO、GEAR、GAUGE_SHATTER、HIT_L）可以是整套最響的；UI 與線索板的小音效可以保持在較低位準（遊戲端會對每個 cue 個別調音量，不需要先壓低）。
  - 每個 SFX 開頭直接是聲音（不留靜音），結尾有幾毫秒的淡出，避免爆音。
- 授權：**必須能隨遊戲散布與商用**。可接受：CC0、CC BY（需在 CREDITS 記錄姓名與要求的標示文字）、買斷或有商用散布授權的素材包、自製。**不要**：CC BY-NC、CC BY-ND、「僅限個人使用」、GPL、從別的遊戲或影視擷取、授權條款不清楚的 AI 生成內容。
- 每個檔案都要登記在 `audio/CREDITS.md`，建議格式：

| 檔案 | 素材名稱 | 作者／來源網址 | 授權（含版本） | 標示文字 | 取得日期 | 備註（是否暫代） |
|---|---|---|---|---|---|---|

- 若某個檔案只是暫代（例如用別首 BGM 湊數），在備註寫「暫代」，之後好替換。
- 來源是原始專案檔／分軌的話請一併保留，之後要剪短版或接循環時用得到。

## 5. 技術限制與待辦

- **框架現況**：XTAtrium 的音訊只有「單次 cue」：`game.json` 的 `audio.cues` 把 cue 名稱對應到音檔路徑，由流圖的 `sound` 節點播放一次（03 §3.8，後端 miniaudio，可同時多個音效、可調音量）。**沒有循環播放、淡入淡出、交叉淡化、停止。**
- 所以現階段 **BGM 無法在遊戲中播放**。素材到位後，我們會向框架提出循環／淡入淡出／交叉淡化／停止的需求（`todo.md` 已記錄），支援後才接上 BGM。這就是為什麼 BGM 要求無縫循環、整檔當一個迴圈：框架一支援，遊戲就能直接用，不必回頭改檔。
- 音效現在就能接：先收到的音效會先接進遊戲，沒收到的音效遊戲端不播放。
- 沒有「停止」意味著長音效（WIN／LOSE 短曲、ROLLER）只能播到結束，所以才限制在 2.5 秒以內。
- 音檔格式：背景音樂 OGG、音效 WAV（見第 2 節）；循環、停止、淡入淡出由框架 AT-050 提供。
