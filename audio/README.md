# audio/

遊戲的音樂與音效。需求與觸發時機見 `docs/audio-requests.md`，來源與授權見 `CREDITS.md`。`game.json` 的 `audio` 區塊由 `tools/gen_flows.py`（`MUSIC`、`SFX`、`audio_decl`）產生，不要手改。

- `bgm/<ID>.mp3`：背景音樂，`audio.music.<ID>`，分類 `bgm`，循環播放。
- `sfx/<ID>.mp3`：一次性音效，`audio.cues.<ID>`，分類 `se`。

檔案是交付的原檔（MP3，未轉檔、未修改）：BGM 44.1 kHz 立體聲，SFX 48 kHz 立體聲（兩個 SFX 檔內含封面圖，miniaudio 解碼正常）。

## 循環點（2026-11-06 第一批）

每首 BGM 結尾都有 1.3～2.5 秒接近無聲的淡出尾巴，整檔循環會留下空白，所以用框架的 `loopStart`／`loopEnd`（XTAtrium 03 §3.9，PCM 樣本位置，以檔案的 44100 Hz 計）跳過。

量測方式：

```
ffmpeg -i bgm/BGM01.mp3 -af silencedetect=noise=-50dB:d=0.3 -f null -
```

`loopEnd` ＝ 結尾靜音的 `silence_start`（淡出已降到 −50 dB 的位置）**無條件捨去到 0.05 秒**（往前最多 50 ms，仍在淡出尾段），樣本數 ＝ 秒數 × 44100。`loopStart` 只有 BGM09 需要（開頭 0.30 秒靜音）。循環從 `loopEnd` 跳回 `loopStart`；第一次播放仍從檔頭開始。
